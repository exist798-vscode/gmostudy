# GMO 토론 학습지 (gmostudy)

“GMO – 유전자 조작 식품을 먹어도 돼?” 찬반 토론 근거 정리 + 나의 생각 작성용 **웹 학습지**.
학생이 안드로이드 태블릿에서 작성하고, 완료하면 **인쇄 가능한 PDF로 저장·다운로드**한다.

**배포 주소: <https://gmostudy.vercel.app>**

## 구성

- `index.html` — 학습지 본문. 외부 라이브러리·빌드 없음, 오프라인 동작
- `reading.html` — **원문 읽기**(토론 자료 전문). 헤더의 **`📖 원문 보기`** 버튼으로 이동, **`돌아가기`** 로 학습지 복귀 (작성 내용은 그대로 유지)
  - 원문 페이지의 **`🔒 수업자료`** 버튼 → 비밀번호(`asdf`) 입력 시 교사용 지도 자료 표시, **`돌아가기`** 로 원문 복귀.
    화면 안에서만 가리는 방식이라 강력한 보안은 아님(소스에는 포함). 비밀번호는 `reading.html` 의 `LESSON_PW` 에서 변경.
- `slides.html` — **수업 진행용 프리젠테이션**(전체화면 웹 슬라이드 22장, 기술·가정 테마).
  수업자료 안의 **`▶ 프리젠테이션 열기`** 로 새 탭 실행. `→/Space` 다음, `←` 이전, `✕ 나가기`.
  - **패드**: 손가락으로 **좌·우 스와이프**하면 페이지 넘김(가벼운 탭도 좌·우로 이동), 툴바 `‹ ›` 버튼도 있음.
  - **애플 펜슬**: 슬라이드 위에 바로 **필기**(필압 반영). 색(빨강·파랑·검정)·지우개·`이 장 지움` 툴바, `✎ 손가락 필기` 를 켜면 손가락·마우스로도 필기. 필기는 슬라이드별로 세션 동안 유지(새로고침 시 사라짐).
  - 외부 라이브러리 없음(웹폰트 CDN만 사용, 오프라인 시 시스템 폰트로 대체).
- 쟁점 4개(안전성 / 환경·경제 / 식량 문제 / 먹거리 선택권)마다 찬성·반대 근거 입력
- 각 항목에 참고용 `도움말` 토글, 글자 수 표시, 자동 높이 조절
- **나의 생각**: 입장 선택(찬성/반대/고민 중) + 그렇게 생각하는 까닭 + 알게 된 점·느낀 점
- 입력 내용은 브라우저에 자동 저장(localStorage) — 실수로 닫아도 복구
- **‘제출하기’ 버튼** — 학생 응답을 구글 스프레드시트로 수집 (설정 시)
- 원본 학습지: `GMO - study.pdf`

## PDF 저장 방법 (학생용)

1. 학습지를 모두 작성한다.
2. 하단 **`PDF로 저장`** 버튼을 누른다.
3. 인쇄 화면에서 **대상(프린터)** 을 **‘PDF로 저장’** 으로 바꾸고 저장한다.
   - 파일명은 `GMO토론학습지_이름.pdf` 로 자동 지정된다.
4. 저장된 PDF는 태블릿의 **다운로드** 폴더에 들어간다.

원본 학습지(찬성/반대 표) 형태 그대로 A4 세로로 출력된다.

## 응답 수집 (구글 스프레드시트)

학생이 **‘제출하기’** 를 누르면 학습지 내용이 구글 스프레드시트에 한 줄씩 쌓인다.
구글 Apps Script 웹 앱만 배포하면 되고 별도 서버는 없다.

- 설정 순서: **[SETUP-스프레드시트.md](SETUP-스프레드시트.md)**
- 스크립트: `apps-script/Code.gs`
- 연결 지점: `config.js` 의 `submitUrl`
- `submitUrl` 이 비어 있으면 ‘제출하기’ 버튼은 숨겨지고 PDF 저장만 동작한다.

## 로컬에서 실행

```bash
node server.js        # 기본 포트 5173
node server.js 8080   # 포트 지정
```

- 이 PC: `http://localhost:5173/`
- 같은 Wi-Fi의 태블릿: 실행 시 표시되는 `http://<PC-IP>:5173/`
  (학교망은 기기 간 통신이 차단될 수 있음 — 그 경우 아래 배포 방식 사용)

정적 파일이므로 `index.html`을 파일로 바로 열어도 대부분 동작한다.

## 배포 (Vercel)

**운영 주소: <https://gmostudy.vercel.app>** — 학생에게 이 링크를 배포한다.

- GitHub `main` 브랜치에 `git push` 하면 Vercel이 자동 재배포한다.
- 설정: Application Preset `Other`, 빌드 없음, `vercel.json`이 루트를 정적 서빙.
